# Portfolio Lacynia - Cynthia Reydellet

Site web portfolio/biographie pour Cynthia Reydellet, entrepreneure en marketing digital.

## 🎨 Caractéristiques

- **Design responsive** : Optimisé pour desktop, tablette et mobile
- **Framework** : Bootstrap 5.3.2
- **Couleurs** : Vert olive (#6B7E52) + Beige champagne (#F5E6D3)
- **Sections** :
  - Accueil avec introduction
  - Biographie complète
  - Services (3 packs de formation)
  - Témoignages clients
  - Formulaire de contact

## 📁 Structure des fichiers

```
lacynia-portfolio/
├── index.html          # Page principale
├── style.css           # Styles personnalisés
├── script.js           # JavaScript pour interactions
├── README.md           # Documentation
└── images/             # Dossier pour les images
    ├── profile.jpg         # Photo de profil
    └── testimonials/       # Screenshots de témoignages
        ├── testimonial1.jpg
        ├── testimonial2.jpg
        └── testimonial3.jpg
```

## 🚀 Installation

1. **Téléchargez tous les fichiers** dans un dossier `lacynia-portfolio`

2. **Créez le dossier images** :
   ```
   lacynia-portfolio/images/
   lacynia-portfolio/images/testimonials/
   ```

3. **Ajoutez les images** :
   - Photo de profil de Cynthia → `images/profile.jpg`
   - Screenshots des témoignages → `images/testimonials/testimonial1.jpg`, etc.

4. **Ouvrez `index.html`** dans votre navigateur
